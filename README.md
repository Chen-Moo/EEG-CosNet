# About EEG-CosNet
We propose EEG-CosNet, a deep learning architecture designed for EEG recognition. It replaces conventional convolutional kernels with specially designed cosine-based convolutional kernels to better capture the characteristics of EEG signals and improve feature extraction for EEG-related tasks.

EEG-CosNet supports flexible input channel configurations, allowing it to automatically process EEG signals with different numbers of channels, including commonly used configurations such as 3, 6, 7, 19, 64, and 128 channels. It also incorporates a custom-designed Feature Refinement Module (FRM) to further refine and stabilize high-dimensional EEG representations.
